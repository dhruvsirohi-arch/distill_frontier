Sim-to-policy distillation · SO-101 arm

A language model that learned to move a robot.

We taught Qwen3-1.7B to pick up a bowl and place it on a table by watching a scripted expert in simulation. It reads the scene as JSON and writes the next motor command. On 100 scenes it had never seen, it succeeded 90 times, up from 0 before training, and never produced a malformed command.

How it works

Five stages, one laptop, zero cloud.

Every stage is a single command, fully seeded and reproducible. The language model never sees pixels or a custom action head. Robot control becomes a chat turn: an observation goes in, a JSON action comes out.

Prompt: what the model seesmm · deg

    
Completion: what it writesgreedy

      
One decision is a straight-line Cartesian move, a gripper command or done. An IK controller executes it in MuJoCo. Anything unreachable or off-schema is rejected, never executed.

  






  
Training data

  
Taught by example: 2,000 demonstrations, curated to 700.

  
A scripted expert sees exactly what the model sees and solves the task in roughly ten decisions. We vary approach side, grasp point, lift height, waypoints and release point, so the model learns the task rather than one trajectory. Then we keep only the cleanest, most diverse episodes.

  

  

    
Curation funnelquality → diversity

      

      
Filters drop collisions, missed grasps, tight placements and redundant moves. Selection fills a 5×5 position grid × 4 bowl orientations evenly and removes near-duplicates. The split is by episode, so validation never leaks into training.

Honest limits · what's next

  
It imitates brilliantly. Next, it learns to recover.

  
The teacher almost never fails, so the student almost never saw a missed grasp. When one happens, it carries on as if holding the bowl. That's the classic imitation-learning gap, and there's a well-known fix.

  

    

      

    
The planin order of cost

      
Let the student drive, and let the teacher correct it.

      
DAgger: roll out Qwen, have the expert label the states Qwen actually reaches (missed grasps included), and retrain. Combined with perturbed demos and a full 2-epoch run (this one stopped at 0.91 epochs to fit a time budget), that targets the remaining ten points.
